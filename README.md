# Smart Manual Timetable System

MVP-прототип интерактивной системы ручного составления университетского
расписания: пул нераспределённой нагрузки, drag-and-drop в сетку «дни ×
пары», проверка конфликтов в реальном времени, умный выбор аудитории.

Дизайн и обоснование решений: [docs/superpowers/specs/2026-09-14-timetable-system-design.md](docs/superpowers/specs/2026-09-14-timetable-system-design.md).

## Требования

- Python 3.11+
- Node.js 18+

## Запуск бэкенда

```bash
cd backend
python -m venv .venv
```

Активация окружения:

```bash
# Windows
.venv\Scripts\activate
```

```bash
# macOS / Linux
source .venv/bin/activate
```

Установка зависимостей и наполнение БД тестовыми данными:

```bash
pip install -r requirements.txt
python seed.py
```

`seed.py` пересоздаёт `timetable.db` с нуля — можно перезапускать в любой
момент, чтобы сбросить расписание к исходному состоянию.

Запуск сервера:

```bash
uvicorn main:app --reload
```

API поднимется на `http://127.0.0.1:8000`.

### Проверка бизнес-логики

```bash
python test_validation.py
```

Должно напечатать `OK`.

## Запуск фронтенда

В отдельном терминале:

```bash
cd frontend
npm install
npm run dev
```

Открыть `http://localhost:5173`. Vite проксирует запросы `/api` на
`http://127.0.0.1:8000`, поэтому бэкенд должен быть уже запущен.

## Как пользоваться

1. Слева — карточки нераспределённой нагрузки, справа — сетка «дни × пары».
   Кнопка «Составить автоматически» стирает текущую расстановку и строит
   расписание заново: старается не оставлять окон между парами у групп и
   не менять аудиторию/корпус без необходимости. Часы, для которых не
   нашлось подходящей аудитории, остаются в пуле — сколько именно, видно
   в уведомлении сверху.
2. Перетащите карточку на ячейку — рамка подсветится зелёным (можно
   ставить), жёлтым (можно, но есть предупреждение — например, не хватает
   мест) или красным (нельзя: аудитория/преподаватель/группа заняты).
3. При отпускании на зелёную или жёлтую ячейку откроется список аудиторий,
   отсортированный по пригодности — выберите нужную.
4. Уже поставленную пару можно перетащить в другую ячейку (перенос) или
   убрать кнопкой «×» рядом с ней — она вернётся в пул.
5. Переключатель сверху меняет, что показывает сетка и пул: по группам, по
   аудиториям или по преподавателям.
6. Вкладка «Справочники» — создание, редактирование и удаление корпусов,
   аудиторий, преподавателей, групп, предметов, слотов и самой нагрузки.
   Удаление каскадное: например, удаление преподавателя удаляет все его
   карточки нагрузки вместе с уже расставленными по ним парами.
